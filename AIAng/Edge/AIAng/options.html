AI 연결

LM Studio 같은 OpenAI 호환 서버 또는 Chrome 내장 Gemini Nano를 선택하세요.

모델을 시스템 메모리(RAM/VRAM)에 계속 올려두어 첫 요청 시의 긴 로딩 지연(Cold Start)을 방지합니다.

⚠️ 약 1.5~2GB의 시스템 메모리를 상시 점유하며, 브라우저가 모델을 언로드하지 못하도록 백그라운드에서 주기적으로 소량의 핑을 보냅니다. 랩탑(노트북)의 경우 배터리 소모가 증가할 수 있습니다.

Gemini Nano는 지원되는 데스크톱 Chrome과 기기에서만 작동합니다. 한국어 사용에는 Chrome의 다국어 Prompt API 지원이 필요하며, 첫 사용 시 모델을 내려받을 수 있습니다. *모델의 문맥 처리 한계로 인해 게시물 작성 시 본문의 맞춤법, 경어체로 교정, 문장 개선 기능이 올바르지 않을 수 있습니다.

게시물 분석

본문의 이미지와 유튜브·트위터·인스타그램 등 외부 임베드의 화면을 캡쳐하여 게시물 요약과 ‘이 게시물을 읽으세요’ 대화에 사용합니다. 이미지 지원 모델에는 캡쳐를, Edge AI에는 캡쳐에서 인식한 글자를 전달합니다. 영상 재생 내용과 음성은 포함되지 않습니다.

캡쳐를 켜고 저장하면 브라우저가 모든 사이트 접근 권한을 요청합니다. 화면 캡쳐 API에 필요한 권한이며, 캡쳐 요청은 다모앙 게시물에서만 처리합니다.
